# Fortress Clean

A production website built for a local cleaning service business to establish its online presence, present service offerings, and help customers request cleaning services.

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Static export with Cloudflare Pages deployment

## Running Locally

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Build the production site:

```bash
pnpm build
```
